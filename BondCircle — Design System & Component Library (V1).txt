24. Performance Standards

Initial load target: under 2 seconds on a good connection

Optimised image loading

Lazy loading for archived circles

Pagination for long activity feeds

25. Development Rules

Every UI element must come from this component library.

Do not create duplicate button styles.

Do not invent new colours without updating the design system.

Do not change spacing rules.

Do not create one-off components when an existing component can be reused.

This design system is the foundation for all current and future BondCircle interfaces.
